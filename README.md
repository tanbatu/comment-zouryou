コメント増量は、ニコニコ動画のコメント数を増量、及び全コメ表示がブラウザ上で出来る拡張機能です。

## インストール
1.[リリースページより](https://github.com/tanbatu/comment-zouryou/releases)Source code (zip)をダウンロード、展開する。

2.Chromeで「<strong>chrome://extensions</strong>」にアクセスする。

3.右上のデベロッパーモードをオンにして、「<strong>パッケージ化されていない拡張機能を読み込む</strong>」を選択する。選ぶのは、`manifest.json` が直下にあるフォルダ（この作業ツリーなら `C:\Users\akito\Downloads\comment-zouryou`）です。`Downloads` 親フォルダ、zipファイル、`manifest.json` 単体は選択しないでください。

読み込み後に拡張機能一覧へ「コメント増量」が1件追加されます。追加されない場合は、同じ画面の「エラー」を開くと manifest の読み込み理由を確認できます。

## 使い方
[note記事を御覧ください。](https://note.com/tanbatu/n/n3837f4137cd9)

動画プレイヤーの設定ボタンの左側にある「ALL」を押すと設定パネルが開きます。「倍」は取得するコメントページ数の目安です。5倍なら各コメントスレッドを最大5ページ取得します。現行APIの1ページは最大約250件なので、4万件ほどある動画をほぼ全件取得するには160〜170倍ほど必要です。値を大きくすると過去コメントが増えますが、取得と描画に時間がかかります。パネルの「読み込み開始！」を押すと取得が始まり、完了すると取得したコメントが動画上に描画されます。ログイン中は指定した始点から過去コメントを取得し、ログアウト中は取得できる最新コメントへ自動的に切り替わります。

取得総数は「ログを表示」をオンにすると、ログの「○件のコメントを読み込みました」で確認できます。「コメント描画数を表示」は動画上に `Count:N` を表示しますが、現在の描画対象数であり取得総数とは異なる場合があります。

## 注意
大量のコメントを処理する為、コンピューターのスペックによってはフリーズする恐れがあります。

現行のニコニコ動画では、ログイン中は指定した始点から過去コメントを追加取得できます。ログアウト中は API の制限により直近コメントへ自動的にフォールバックします。
